# 接受所有 Cookie

一台复古电脑，一场被曲奇打断的冒险。打开 `COOKIE QUEST.exe`，进入小游戏与曲奇网页，再看看最后会发生什么。

## 开始游玩

在电脑浏览器中打开本仓库的 GitHub Pages 网站，点击开机并打开桌面的游戏图标。第一次播放声音需要点击页面；右下角扬声器可控制声音。

- 移动：← / → 或 A / D
- 跳跃：空格、↑ 或 W
- 下蹲：↓ 或 S
- 暂停：Esc
- 静音：M

网页阶段用鼠标探索窗口。体验四个不同故事后可返回游戏，也可继续逛；失败也算一次体验。最后的曲奇可以直接点击互动和切换，黑色问号曲奇可以 DIY。

本版本按电脑的键盘与鼠标设计，建议使用桌面浏览器。泰国炸花的摄像头手势是可选玩法，不开启摄像头也可以用鼠标完成。

## 本地预览

本仓库已经包含十个模块及其图片、视频和音乐，无需构建工具。发布路径为 `/accept-all-cookies/`。本地预览时，将仓库文件夹命名为 `accept-all-cookies`，在它的上一级文件夹启动静态服务器，例如：

```sh
python3 -m http.server 8080
```

然后打开 `http://localhost:8080/accept-all-cookies/`。请通过网页地址打开，不要直接双击 HTML 文件。

## 内容与资料

- 十个故事：姜饼人、Tim Tam、泰国炸花、Khapse、章鱼仙贝、Kungu、迪拜软曲奇、曲奇乐队、幸运饼干、Oreo。
- 食品资料及照片署名保留在 `cookie-quest/data/`；实际资料来源也可在曲奇详情中查看。
- 音频来源保留在 `cookie-quest/assets/audio-sources.txt`，各独立模块的素材说明随模块保留。
- 像素插画和创作实验是视觉表达，不等同于实物照片或可食用配方。

网站在浏览器本地运行，无需注册。网页需要使用的摄像头由浏览器另行询问，生成的曲奇图片由使用者主动保存。
